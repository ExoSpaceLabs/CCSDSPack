ccsds_packet_view_t *  view_out,

)

Parses the next framed packet and advances the cursor transactionally.

The returned packet view aliases the original stream buffer. CCSDS_STATUS_NO_DATA is returned when the cursor is exactly at end-of-stream. On any failure the cursor offset is unchanged.

frame_consumed_out receives packet bytes plus the optional four-byte sync word.
