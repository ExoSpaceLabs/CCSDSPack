Detailed Description

Plain field representation of the six-byte CCSDS Space Packet primary header.

Field widths are validated only when the structure is assigned to Header or Packet. Packet Data Length stores the CCSDS encoded value N-1, where N is the total packet-data-field size including optional packet error-control bytes.
