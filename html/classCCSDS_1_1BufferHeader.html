Detailed Description

Opaque secondary header that stores bytes without interpreting them.

BufferHeader is used by setDataFieldHeader(bytes) and explicit-size parsing overloads. It is suitable when a project needs a secondary-header boundary but no typed decoder. Its registered type name is "DataOnlyHeader".
