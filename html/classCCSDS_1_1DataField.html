Detailed Description

Owns the optional secondary header and application-data bytes of one packet.

DataField stores packet data-field content only. It does not include the six-byte primary header or optional packet error-control bytes. Capacity is shared between secondary-header and application-data bytes.

Built-in secondary-header registrations include BufferHeader and the legacy, project-specific PusA/PusB/PusC formats. Custom types can be registered through RegisterSecondaryHeader().

Inspection APIs do not call update(). serialize() is the explicit finalization path: it optionally invokes the installed secondary header's update() method and then concatenates secondary-header and application-data bytes.
