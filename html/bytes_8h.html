typedef enum ccsds_byte_order ccsds_byte_order_t

Explicit wire byte order for generic integer fields.

CCSDS-defined primary headers and CUC fields remain big-endian by standard. Mission/custom fields may select either order explicitly instead of depending on the host CPU byte order.
