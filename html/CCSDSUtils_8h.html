Parameters
dataBytes processed in order.
polynomialGenerator polynomial; defaults to 0x1021.

Calculated 16-bit CRC.

The default parameters implement CRC-16/CCITT-FALSE. Packet uses this function over finalized primary-header and packet-data-field bytes, excluding the CRC itself.
