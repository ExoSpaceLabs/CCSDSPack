Detailed Description

Generates, stores, parses, and validates one CCSDS packet-identifier stream.

The complete Packet template is the receive/generation contract. If the template contains a PUS/custom secondary-header object, that object is also the parsing prototype and carries any PUS tailoring. Manager owns no independent profile.
