◆ ccsds_packet_coherence_input_t

typedef struct ccsds_packet_coherence_input ccsds_packet_coherence_input_t

Plain generic packet-coherence facts consumed by the C validator.

primary_header_state_valid carries ownership-layer invalid state that cannot be reconstructed from retained field values alone. secondary_direction uses CCSDS_PACKET_DIRECTION_* constants. crc_checked controls whether the CRC16 validation code is included in the report.

◆ ccsds_pus_coherence_input_t

typedef struct ccsds_pus_coherence_input ccsds_pus_coherence_input_t

Plain PUS coherence facts consumed by the C validator.

revision uses the public PUS revision values 1 (A) and 2 (C). direction uses CCSDS_PACKET_DIRECTION_* values and packet_type is the CCSDS primary-header Packet Type bit. serialized aliases the exact secondary-header bytes.

The adapter supplies object-state facts that cannot be reconstructed from bytes alone, while the C validator owns the actual report decisions.
