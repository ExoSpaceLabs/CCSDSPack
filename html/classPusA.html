Detailed Description

Legacy fixed-size six-byte telemetry-oriented secondary header.

The serialized form contains project-specific version, service type, service subtype, source ID, and application-data length fields. update() derives the stored data length from the owning CCSDS::DataField when automatic updates are enabled.

Warning
This compatibility type is not an ECSS PUS conformance declaration.
